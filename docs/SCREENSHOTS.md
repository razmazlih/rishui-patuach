# הצילומים בתיעוד

ארבעה צילומים מהממשק האמיתי מציגים את מסלול השימוש בלי לקרוא את הוראות ההתקנה: חיפוש, תקציר דוח, בחירה בדיווח בעלות ובדיקת מקור.

## מה צולם

- נלכדו ב־6 בנובמבר 2026, מהקוד ב־`374ee3f`, באמצעות Chromium ו־Playwright.
- האתר נבנה כ־production build והופעל מקומית על loopback בלבד, עם `DATA_MODE=demo`.
- נטענו רק ששת קובצי ה־fixtures הסינתטיים שבמאגר, דרך היבואן המקורי, למסד PostgreSQL זמני ונפרד. לא נעשה שימוש במסד קיים או בנתוני אמת.
- `01234567` הוא מספר הבדיקה של ההדגמה. שמות, מפרטים, מועדים ודיווחי הבעלות בתמונות הם נתוני בדיקה, ולא מידע על רכב אמיתי.
- גודל חלון הצילום הוא 1440×1000. תמונות הדוח, הבעלות והמקור נחתכו בגבולות רכיבי הממשק; לא נוספו נתונים, לא שונו תוויות ולא הוסתרו מגבלות באמצעות עריכת תמונה.
- התמונות מתעדות את חוויית השימוש בלבד. הן אינן מאמתות מקורות ממשלתיים, כיסוי נתונים או זמינות של אתר ציבורי. לא בוצע deploy.

## שחזור ועדכון

השתמשו בעותק מקומי ובמסד בדיקות נפרד. אין לצלם נתוני אמת או לטעון את ההדגמה למסד של משתמש. דרישות ההתקנה והאפשרויות להפעלת PostgreSQL מפורטות ב־[README](../README.md).

אחרי `make setup`, מול מסד הבדיקות שלכם:

```sh
export DATABASE_URL='postgresql://USER:PASSWORD@127.0.0.1:PORT/DISPOSABLE_DEMO_DB'
export DATA_MODE=demo
make migrate DATA_MODE=demo DATABASE_URL="$DATABASE_URL"
make demo DATA_MODE=demo DATABASE_URL="$DATABASE_URL"
npm run build
npm run start
```

החליפו את פרטי מסד הדוגמה בערכים המקומיים שלכם; אין לשמור סיסמאות ב־Git. השאירו את השרת פועל, ובטרמינל נוסף מאותה תיקייה:

```sh
npx playwright install chromium
node scripts/capture-docs.mjs
```

אם השרת פועל בפורט מקומי אחר, הגדירו `SCREENSHOT_BASE_URL`. לדוגמה:

```sh
SCREENSHOT_BASE_URL=http://127.0.0.1:3139 node scripts/capture-docs.mjs
```

אפשר לבחור Chromium שכבר מותקן באמצעות `SCREENSHOT_CHROMIUM_PATH`. הסקריפט מסרב לכתובת שאינה loopback, בודק שה־API מחזיר `demo`, וממתין לבאנר ההדגמה לפני שמירת תמונות. ההגנות האלה אינן מחליפות בדיקה ידנית של התוכן ושל המסד שנבחר.

פתחו את ארבע התמונות ובדקו קריאות, חיתוך, סימון נתונים סינתטיים והיעדר מידע אישי לפני commit. אין לפרסם את האתר או נתונים ללא האישור הנדרש בכללי הפרויקט. עצרו את השרת אחרי הצילום.

## מה אומת בהרצה זו

- production build ובדיקת TypeScript עברו.
- 10 בדיקות TypeScript ו־11 בדיקות יחידה של היבואן עברו.
- ארבע בדיקות API מול ההדגמה עברו: מבנה הדוח, שמירת אפס מוביל, קלט לא תקין והיעדר מידע בלי טענת תקינות לרכב.
- צילום בדפדפן אימת חיפוש מוצלח והצגת הדוח. בדיקת רוחב במסך 390×844 לא מצאה גלילה אופקית בעמוד הכניסה.
- זו אינה הרצת כל בדיקות האינטגרציה או בדיקות `live`; הן לא נדרשו לעדכון התיעוד ולא הורצו כאן.
