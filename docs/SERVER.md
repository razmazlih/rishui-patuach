# הפעלה עתידית בשרת — ללא פריסה כעת
1. שרת Linux עם Docker Compose, נפח עבודה מספיק למקור, staging, אינדקסים וגרסאות היסטוריות. לאמוד נפח על מקור אמיתי לפני רכישת משאבים.
2. לבנות image מהקוד בלבד. למפות raw לקריאה בלבד; work/reports לנתיבים פרטיים. אין להעלות מאגרים ל־public או לשלוח ל־AI.
3. PostgreSQL ברשת פרטית בלבד, סיסמה חדשה ב־secret חיצוני, גיבויים מוצפנים ובדיקת שחזור. ליצור תפקיד קריאה בלבד ליישום ותפקיד כתיבה נפרד ליבואן; ההרשאות המקומיות הפשוטות אינן תצורת ייצור.
4. DATA_MODE=live בלבד אחרי אימות מקורות ומיפויים; להפעיל migration ויבוא ב־CLI תחזוקתי, לבדוק דוחות ולוודא שניתן לחזור לגרסה קודמת.
5. Reverse proxy עם TLS, מגבלות בקשה וקצב, טיימאאוט ו־trusted proxy מוגדרים. מגבלת הקצב המובנית גלובלית לתהליך ומספיקה להרצה מקומית; לריבוי תהליכים יש להוסיף הגבלה משותפת בפרוקסי. לא לחשוף דוחות, debug, CLI או פורט מסד.
6. בדיקת חיפוש מלא, RTL במובייל, זמינות מקורות, עומס עם נתונים אמיתיים, חיבורי מסד וזיכרון. לתעד תאריך מקור ורמת דיוק, ולהגדיר סף התיישנות מוסכם למקורות.
7. לפני פרסום: לאמת זכויות שימוש, תכולה וכיסוי, מדיניות פרטיות ומגבלות המידע. פרסום, תשלום ושינוי הרשאות דורשים אישור הבעלים.
לא נוצרו שירותים בענן ולא נרכשו משאבים.
